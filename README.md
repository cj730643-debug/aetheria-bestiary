# 艾瑟拉大陆生物图鉴

艾瑟拉大陆的动物与植物百科网页，记录原始物种、地方演化分支、食性、栖息地、生存特征及生态关系。

## 在线预览

启用 GitHub Pages 后，可通过以下地址访问：

https://cj730643-debug.github.io/aetheria-bestiary/

## 项目文件

- `index.html`：图鉴网站首页，包含目录导航、关键词搜索、动物与植物详情及响应式布局。
- `README.md`：项目说明。

## 本地预览

下载或克隆仓库后，直接用浏览器打开 `index.html` 即可，无需安装依赖或启动服务器。

## 启用 GitHub Pages

在仓库中打开 **Settings → Pages**：

1. 在 **Build and deployment** 下选择 **Deploy from a branch**。
2. Branch 选择 `main`。
3. Folder 选择 `/ (root)`。
4. 点击 **Save**。

等待 GitHub Pages 部署完成后，即可使用上面的在线地址。

## 后续维护

网页主体位于 `index.html`。后续新增或修改生物资料、目录和搜索内容时，更新该文件并提交到 `main` 分支即可触发网站更新。

本项目是生物设定图鉴，不记录世界回合、种群数量或世界进度存档。
