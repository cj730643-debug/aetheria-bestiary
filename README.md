## 重要设定口径

地图是世界观方位示意图，不是精确比例尺地图。五大地区的相对位置与地貌作为当前图鉴采用的地理基准；河流、山脉及气候描述属于可继续扩展的世界设定。

此前未明确给出的生物数值，本次补全为图鉴设定值，属于可继续调整的虚构世界参数，不代表现实动物数据。后续若用户明确修改某项数值，以最新确认版本为准。

## 本地预览与维护

下载或克隆仓库后，直接用浏览器打开 `index.html` 即可预览，无需安装依赖。

后续新增或修改生物、植物、地图区域和生态关系时，更新 `index.html` 并提交到 `main` 分支，GitHub Pages 会自动重新部署。
